

# 📂 AutoFile

AutoFile is a web-based tool that helps you organize files quickly by uploading them, renaming them in bulk, and keeping everything structured in a clean way.

It’s built for people who deal with a lot of files and don’t want to waste time renaming or sorting everything manually.

## 🌐 Live App

[https://autofile.vercel.app](https://autofile.vercel.app)

## 🧠 Overview

AutoFile lets you upload files directly into the browser and perform actions like mass renaming and organization in seconds. The focus is speed, simplicity, and making repetitive file tasks way easier.

## ⚙️ Features

* 📤 Upload files directly in the browser
* ✏️ Bulk rename files (mass editing names at once)
* 📁 Organize files quickly without manual effort
* ⚡ Fast and simple UI
* 💻 No install needed (runs fully online)

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* Vercel (deployment)

## 📦 How to Use

1. Open the website
2. Upload your files
3. Select rename or organize options
4. Apply changes instantly

## 💡 Example Use Cases

* Renaming hundreds of images for a project
* Cleaning up messy download folders
* Organizing school or work files fast

## 🚧 Future Improvements

* Drag and drop sorting
* File preview support
* Save/export organized files as zip
* More advanced renaming rules (patterns, numbering, prefixes)
* Cloud storage integration
